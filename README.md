### <samp>[ ARCHIVE / 00 ]</samp>

<br>

There are things here that claim to work.

Some of them do.

The distinction is under investigation.

I build systems around **proof, execution, provenance, money, and the places where software becomes difficult to believe**.

Not everything below was intended to become a product.

That is probably why some of it survived.

<br>

---

### <samp>[ ARTIFACT / I ]</samp>

<br>

> ### `StrayInk`
>
> An agent says:
>
> `done`
>
> StrayInk asks for the receipt.
>
> Execution becomes a signed object — Ed25519, Merkle-batched, independently checkable. The machine may still be lying. At least the lie has to leave evidence.
>
> ```
> receipt      signed execution record
> batch        Merkle audit pack
> hash         OptiHash256-v1
> parity       Python ≡ TypeScript
> payment      x402
> ```
>
> The interesting question is not whether an agent can act.
>
> It is what remains after it claims that it acted.

<br>

### <samp>[ ARTIFACT / II ]</samp>

<br>

> ### `HomeCRU`
>
> Houses are strange databases.
>
> Money moves before work is visible.
> Work becomes visible before it becomes accepted.
> Acceptance becomes memory.
>
> HomeCRU records the interval.
>
> ```
> attendance    supervisor · camera · GPS
> planning      deterministic work-unit construction
> payment       stage-paid
> record        scope · progress · handover
> ```
>
> Built around real crews and real sites in Jaipur.
>
> The software is less interesting than the disagreement it attempts to make impossible.

<br>

### <samp>[ ARTIFACT / III ]</samp>

<br>

> ### `Economic Diff Engine`
>
> A pull request arrives carrying a second payload:
>
> **what will this code cost?**
>
> The engine follows paid API calls through the syntax tree and leaves the answer where the decision already happens — inside the PR.
>
> ```
> parser       tree-sitter
> output       lower bounds
> uncertainty  ≥
> failure      unbounded paid-call loops
> interface    one comment
> ```
>
> It does not predict the future.
>
> It calculates the portion of the future that has already been written.
